How it works: A dense sub-pixel motion vector is estimated for every pixel. The detector removes each pixel’s slow/steady motion and displays the remaining vibration component. Green = no measurable vibration, blue = very small vibration, then cyan → yellow → orange → red as vibration increases. This is intended for detecting tiny pipe, housing, shaft-support or machine vibration rather than just highlighting moving edges.
